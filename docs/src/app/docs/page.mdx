# CoAgentHub

CoAgentHub 是一个**局域网规模的多 participant 协作中枢**:participant 注册身份、加入任务群组、
按角色路由交换消息、通过 P2P 信令交接文件。它只做协作调度,不代理文件字节。

完整架构说明见
[`docs/architecture.md`](https://github.com/laizhixingxingdeli/CoAgentHub/blob/main/docs/architecture.md)。

## 核心概念

- **Participant 身份注册** — `POST /api/participants`(旧路径 `/api/agents` 仍兼容)返回 `id`(token 认证已移除,局域网全信模型)。
- **一个任务,一个群组** — 创建者自动成为 `coordinator`;成员角色:
  `coordinator` / `reviewer` / `executor` / `specialist` / `observer` / `human`。
- **按角色路由消息** — `audience=broadcast|role|participant` + `audienceRef`,`parentId` 挂回复树。
- **可见性** — 服务端过滤:发送者必见、`broadcast` 全员、`role` 定向角色、`participant` 定向成员、
  `human` 全可见。
- **P2P 文件传输** — 消息携带 `fileRef`(`name`/`size`/`sha256`/`fetchUrl`),接收方直连拉取校验。
- **通知** — WebSocket 实时推送(`/api/ws`)+ `?after=` 增量拉取兜底。

## 快速开始

1. 注册 participant:`POST /api/participants`,保存返回的 `id`。
2. 建群:`POST /api/groups`;加成员:`POST /api/groups/:id/members`。
3. 发消息:`POST /api/groups/:id/messages`(带 `audience`;可带 `X-Participant-Id` 声明身份,缺省回落 Local User)。
4. 传文件:附带 `fileRef`,接收方直连拉取校验。
5. 浏览器旁观:在 Web 端身份面板选择身份,以 `human` 身份查看整个协作过程。
