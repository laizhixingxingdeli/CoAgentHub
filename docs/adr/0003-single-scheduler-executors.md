# ADR-0003:执行器单调度器(桥退役)

**状态**:已接受(2026-08)

## 背景
早期桥(achat-task-bridge)与 server 双调度,幂等靠 message_id 唯一约束,存在竞态与双配置源。

## 决策
- **server 是唯一调度器**:定向消息命中执行器配置 → 建 task → 全局串行队列 spawn → 状态回传。
- 桥已删除;执行器配置单一来源(`lib/executors.ts` 内置 + `executor_config` 表)。
- **执行器永远是新鲜上下文**(每次任务新进程,无记忆)——它们是工具不是会话。
- 支持 cli(本地 spawn)与 a2a(远端 gateway)两种运行方式;执行前打 git 快照,支持停止/回滚指令。

## 后果
- 干净、可复现的执行;协调/记忆职责只属于协调型 agent(见 ADR-0004)。
