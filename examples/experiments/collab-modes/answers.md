# 答复单（只给答复人看）

**谁都不要把这份文件给 agent 看**：检视者会话、direct 模式的主控会话、协调者、执行者都不行。
只在 agent **主动提问**时（升级单、执行者 blocked、主控会话问你），由你照下面原文回答，并在记录表里记一次「提问」。

| # | 对方问的大意 | 原文回答 |
|---|---|---|
| Q1 | 交易日早于该币种第一条汇率（或该币种根本没有汇率）怎么办？ | 报错退出，退出码 1；stderr 写明缺汇率的币种代码，以及最早一笔缺汇率交易的日期；stdout 不输出任何报表内容。不要跳过这些交易，也不要套用最早的汇率。只检查本次报表范围（`--month` 过滤之后）内的交易。 |
| Q2 | 同一币种、同一生效日期重复 `rates add` 怎么办？ | 以后写的为准，覆盖旧值；`rates list` 里只出现一条。 |
| Q3 | 汇率存在哪里（ledger.json 还是单独文件）？ | 由你决定，但要遵守 docs/CONVENTIONS.md 的存储约定。 |
| Q4 | 币种代码大小写、舍入方式、错误格式、旧数据怎么处理？ | 见 docs/CONVENTIONS.md。 |
| — | 其他任何问题 | 按 docs/CONVENTIONS.md 和你的判断。 |

只答被问到的那一条，不要顺带透露别的条目；也不要提示对方「还有别的坑」。
